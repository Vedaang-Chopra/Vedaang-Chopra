CAD repair without fine-tuning

A model that writes CAD code, and gets told exactly which step went wrong. Owner, CORE Robotics Lab Ongoing

Language models often write CAD code that runs but builds the wrong part. A score only says "wrong", not where. I let the model see its part after every step, so it can be told which step broke and fix it, with no retraining.

Did not work: How often repair gets the shape right; Richer feedback did not help; A pre-registered gate that failed.

CERBERUS, a resizable vision-language bridge

Teaching a vision-language model to read only the parts of an image that a question needs. Owner, research project Ongoing

Most models cut every image into the same number of pieces, whatever you ask. I want the question to decide how many pieces the model reads. The shared image-and-text base is built. Choosing pieces by question is the next step.

ARTEMIS, routing to the right model

Sending each request to the cheapest AI model that can answer it. Owner, research project Ongoing

Some AI models cost far more than others, and the biggest is not always the best. I built a fair test of which model is good at which task, and a router that picks one per request. So far it has not beaten a simple lookup.

Did not work: ARTEMIS, a learned router that lost.

How far along is it?
  1. BuiltCollect answers from five models on 67,711 questions
  2. BuiltSplit by image so no picture appears in both train and test Found and removed 3,909 shared images that had inflated earlier numbers.
  3. BuiltCost and latency model per call
  4. BuiltBaselines: best single model, per-task lookup, oracle
  5. BuiltLearned router with cost and latency penalties set at decision time Did not beat the per-task lookup on the test split.
  6. PartialServing layer and verifier cascade Code only, never validated on live backends.
